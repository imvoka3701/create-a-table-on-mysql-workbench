Tạo bảng trên MySQL Workbench

Thực hành tạo cơ sở dữ liệu `demo`, kích hoạt và tạo bảng `Student` (id, name, age, country) bằng câu lệnh SQL.

📖 Quy trình thực thi từng câu lệnh theo giáo trình

1

Tạo cơ sở dữ liệu `demo`

Mở tab SQL mới (Ctrl + T) và gõ lệnh: create database demo;. Đặt con trỏ chuột và nhấn Ctrl + Enter để thực thi.

2

Chọn CSDL làm việc: `use demo;`

Thiết lập ngữ cảnh làm việc hiện tại vào database `demo`. Mọi bảng tạo tiếp theo sẽ nằm trong database này.

3

Tạo bảng `Student`

Chạy khối lệnh tạo bảng với 4 trường: id (int), name (varchar(200)), age (int), country (varchar(50)).

🗂 Cấu trúc bảng `Student` & Bảng tra cứu kiểu dữ liệu

1. Cấu trúc trường dữ liệu của bảng `Student`:

Tên cột (Field) Kiểu dữ liệu (Data Type) Ý nghĩa nghiệp vụ Ví dụ dữ liệu
id INT Mã định danh duy nhất của sinh viên 1, 2, 101
name VARCHAR(200) Họ và tên của sinh viên (tối đa 200 ký tự) "Nguyễn Văn Nam"
age INT Tuổi của sinh viên 19, 20, 22
country VARCHAR(50) Quốc gia / quê quán (tối đa 50 ký tự) "Việt Nam", "Hoa Kỳ"

2. Các kiểu dữ liệu thường dùng trong MySQL:

Nhóm kiểu Kiểu dữ liệu Phạm vi / Quy cách Ứng dụng phù hợp
Số nguyên INT 4 bytes (~ -2.1 tỷ đến +2.1 tỷ) Mã ID, số lượng, tuổi, điểm số
Chuỗi ký tự VARCHAR(N) Độ dài thay đổi từ 0 đến N ký tự Tên người, email, địa chỉ, tiêu đề
Chuỗi cố định CHAR(N) Độ dài cố định chính xác N ký tự Mã quốc gia (VN, US), mã tiền tệ (VND, USD)
Số thực / Tiền tệ DECIMAL(M, D) Độ chính xác tuyệt đối không bị sai số Giá bán, tiền lương, doanh thu
Ngày tháng DATE / DATETIME Lưu ngày (YYYY-MM-DD) và giờ Ngày sinh, ngày đặt hàng, thời gian tạo

💻 Kịch bản SQL đầy đủ (create_table.sql) 

-- 1. Tạo cơ sở dữ liệu demo
create database demo;

-- 2. Chọn CSDL demo để làm việc
use demo;

-- 3. Tạo bảng Student
create table Student (
    id int,
    name varchar(200),
    age int,
    country varchar(50)
);

-- 4. Kiểm tra cấu trúc bảng vừa tạo
DESCRIBE Student;

-- 5. Thêm dữ liệu mẫu vào bảng
INSERT INTO Student (id, name, age, country) VALUES
(1, 'Nguyễn Văn Nam', 20, 'Việt Nam'),
(2, 'Alice Johnson', 21, 'Hoa Kỳ'),
(3, 'Kenji Sato', 22, 'Nhật Bản');

-- 6. Truy vấn hiển thị dữ liệu
SELECT * FROM Student;
